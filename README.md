# 仿素记日记 — 本地记事本 PWA

单文件 PWA 笔记应用，数据全部存储在浏览器 IndexedDB 中，无需联网，无需后端。

**在线体验**: https://unplage.github.io/localnote1/

---

## 功能

### 记录
- 笔记 CRUD（标题、正文、分类、时间戳）
- 零依赖富文本编辑器：标题 H1–H3、列表、引用、代码块、加粗/斜体/删除线、前景色/高亮色、对齐、缩进、**链接、图片、表格、分隔线**
- **图片可全屏查看与缩放**：点开笔记里的图片进入全屏查看器，双指缩放、点击/双击放大、拖动平移、双指内收关闭；桌面端另有滚轮与 +/- 按钮
- 粘贴保留格式（Word / 网页的富文本经消毒后插入）
- 全文搜索（标题 + 正文 + 分类名），带纯文本缓存
- 分类管理（名称、颜色、排序），分类色贯穿列表卡片
- 按「今天 / 昨天 / 最近 7 天 / 月份」自动分组
- 自动保存（间隔可配置，1–300 秒）
- 手动插入时间戳（日期/时间/星期/自定义格式）
- **只看不改**：打开、浏览、退出笔记都不会改动笔记的修改时间（含手机输入法空操作 / 临时组合文本撤销），编辑器底部显示的是笔记真实的最后编辑时间

### 数据安全
- **回收站**：删除进回收站，30 天内可恢复，删除后 6 秒内可「撤销」
- **应急草稿**：每次输入都写入 localStorage，覆盖标题/正文/分类，崩溃或被杀也不丢
- **自动快照**：每 5 分钟 + 每日一份，保留最近 10 份，可回滚到任意时间点
- **自动写盘**（Chrome/Edge）：选一个文件，每次保存都写入完整 JSON 备份 —— 浏览器数据被清除也有外部副本
- **导出提醒**：可设 3/7/30 天未导出时提示
- 密码保护（屏幕锁）+ **恢复密钥**：忘记密码可凭密钥重置，不会永久锁死数据
- 多标签页通过 BroadcastChannel 同步，避免互相覆盖

### 离线
- Service Worker 预缓存全部关键资源，**首次访问后完全离线可用**
- 导航请求 4 秒超时回落缓存，弱网不白屏
- 导航响应做内容指纹校验，防止弱网门户的登录页污染离线缓存
- 离线横幅 + 30 秒心跳校准真实连通性
- **离线自检**：一键检查关键资源是否已缓存、数据库是否可读、配额与 SW 状态
- 提示式更新：发现新版本弹出横幅，用户确认后才接管，不静默重载

### 导入导出
- JSON 导出 / 导入（可选「追加」或「替换」，自动跳过重复条目，带进度条）
- Markdown 导出**保留标题层级、列表、加粗、代码块、链接、表格**
- Markdown 导入可回读本应用导出的文件

### 其他
- 浅色 / 深色 / 跟随系统主题（系统主题变化时实时跟随）
- 存储持久化申请 + 配额监控（写满前预警）
- iOS 独立运行支持、PWA 快捷方式（长按图标「新建笔记」）
- 无障碍：恢复页面缩放、ARIA 标注、弹窗焦点管理与 Esc 关闭、键盘可操作列表

## 项目结构

```
localnote/
├── index.html              # 主应用（HTML + CSS + JS 单文件）
├── manifest.json           # PWA 清单
├── sw.js                   # Service Worker（离线缓存 + 更新流程）
├── clear.html              # PWA 缓存清理工具 + 离线可用性自检
├── icons/                  # 应用图标（icon.svg 为矢量源文件，其余为生成位图）
├── favicon.ico             # 标签页图标
├── fontawesome.min.css     # Font Awesome 6.4.0（本地内置，不走 CDN）
├── webfonts/               # 图标字体
└── tools/
    ├── make_icons.py       # 由 icons/icon.svg 重新生成全部图标
    ├── selftest.html       # 浏览器自检页（零依赖，直接打开即可运行）
    └── check_syntax.mjs    # 仓库自检：语法 / manifest / 预缓存清单 / assets 同步
```

## 架构

### 数据层 (`DBManager`)
- **数据库**: `<应用路径>::SimpleNotesDB` (IndexedDB, v3)，按部署路径隔离，不同 PWA 互不共享
- **存储**: `notes` / `categories` / `settings` / `backups` 四个 object store
- **索引**: `notes.category`、`notes.updatedAt`、`notes.deletedAt`（回收站）、`backups.at`
- 打开数据库有超时与 `onblocked` / `onversionchange` / `onclose` 处理，失败时给出可操作的错误面板而不是白屏

### 核心类 (`App`)
- 单一 ES6 class 管理所有 UI 和业务逻辑
- 模块划分：DOM 引用 → 初始化 → 分类管理 → 笔记列表 → 编辑器 → 图片查看器 → 导入导出 → 备份 → 全局事件 → 辅助方法
- **编辑会话令牌** (`_session`)：所有异步保存都必须校验令牌，防止「关闭后立刻新建」把内容写进上一条笔记
- **脏标记** (`_dirty`)：只有用户真的动过内容才允许写库，避免「只是看一眼」也刷新 `updatedAt`；标题回填前先过 `sanitizeTitle`，与 `<input>` 的取值保持一致

## 本地使用

直接用浏览器打开 `index.html`，或启动 HTTP 服务：

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 技术要点

- **零构建**: 单文件 HTML，无构建工具、无 npm 依赖
- **外部依赖**: 无。Font Awesome 6.4.0 本地内置（`fontawesome.min.css` + `webfonts/`），完全离线可用
- **离线使用**: Service Worker 预缓存 + 导航网络优先（带超时与内容指纹校验）
- **数据安全**: 回收站 + 应急草稿 + 自动快照 + 可选自动写盘 + 导出提醒
- **已知边界**: 密码是屏幕锁而非端到端加密，笔记以明文存于本机数据库
